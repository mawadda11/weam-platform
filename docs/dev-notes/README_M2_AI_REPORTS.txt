Weam Milestone 2 - Feature 1: AI Report Analysis

Apply only after Milestone 1 (migration 0004_goals_timeline) is merged.

What this adds:
- Provider-independent AI report analysis gateway.
- Safe local "mock" mode for development/tests; no API key required.
- Optional Gemini multimodal mode through environment settings.
- Structured extraction: summary, findings, needs, recommendations, follow-up actions, goal mentions, evidence, limitations.
- Human-in-the-loop review: draft -> edited + approved/rejected.
- Analysis history is preserved per report/version.
- Report permissions are respected; restricted reports stay restricted.
- No diagnosis, medication advice, or treatment changes are generated by the prompt.
- AI analysis page added to each report.

Important:
- Run pip install -r requirements.txt because pypdf is new.
- Run Alembic upgrade head -> 0005_report_ai_analysis.
- Default WEAM_AI_PROVIDER=mock lets the full UI workflow be tested without a key.
- For real Gemini analysis set:
  WEAM_AI_PROVIDER=gemini
  WEAM_AI_API_KEY=<your key>
  WEAM_AI_MODEL=<supported Gemini multimodal model>

Expected test total after M1 polish + this patch: about 28 tests.
