# Git workflow

- `main` stays stable.
- Use one branch per feature.
- Suggested branch names:
  - `feat/auth`
  - `feat/child-profile`
  - `feat/care-team-permissions`
  - `feat/reports-ai`
  - `feat/voice-updates`
  - `feat/timeline-goals`
  - `feat/ai-assistant`
  - `feat/care-agent`
  - `feat/chat`
  - `feat/centers`
- Merge only after the feature works end-to-end and basic tests pass.
